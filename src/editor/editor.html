    System stats

    CPU and GPU use, video memory, and the frame rate of the app in focus, in a little pixel panel. Add it with System stats above, or use this address as a browser source in OBS:

    Frame rate

    Frame rates come from Intel's PresentMon, included with the app. Windows only shows apps' frame times to members of its Performance Log Users group; turning it on adds you, the same thing the Xbox Game Bar's FPS counter asks for.

    CPU temperature shows up while MSI Afterburner (with CPU temperature on in its Monitoring settings), HWiNFO (with Shared Memory Support on) or LibreHardwareMonitor (with its Remote Web Server on) is running. Windows can't read it by itself.

    How it works

    • Every overlay is a see-through window over everything else, like a browser source in OBS but on your desktop.
    • Unlocked overlays get a dashed outline and a yellow tab. Drag to move, drag the edges to resize.
    • Locked overlays stay put. Unless they're Interactive, clicks go straight through them.
    • The tray icon shows and hides each overlay. Right-click it for everything else.
